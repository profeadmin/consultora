# PROMPT PARA OPENCODE

Crea una página web **estática, profesional, moderna y responsive** para **CONSULTORA ADMIN**, utilizando únicamente **HTML5, CSS3 y JavaScript vanilla**. No uses PHP, bases de datos, frameworks ni backend.

La página debe ser sencilla, visualmente atractiva y enfocada en **mostrar los servicios y conseguir contactos por WhatsApp**.

## Estructura obligatoria

### 1. MENÚ SUPERIOR
- Logo/nombre: **CONSULTORA ADMIN**
- Enlaces: Inicio, Servicios, Nosotros, Contacto.
- Botón destacado: **Hablar por WhatsApp**.
- Menú responsive para móviles.

### 2. HEADER PRINCIPAL
Título comercial que comunique que Consultora Admin ayuda a las empresas a **mejorar su administración y resolver problemas administrativos**.

Incluir:
- Subtítulo breve.
- Botón principal: **Hablar por WhatsApp**.
- Diseño moderno y profesional.
- Elementos visuales relacionados con administración, procesos, estrategia y tecnología.

### 3. SERVICIOS
Mostrar estos 8 servicios en tarjetas modernas:

1. **Consultoría Administrativa**
2. **Planes Administrativos**
3. **Asesoría Administrativa**
4. **Sistemas Administrativos**
5. **Capacitación Administrativa**
6. **Auditorías Administrativas**
7. **Acompañamiento Administrativo**
8. **Outsourcing Administrativo**

Cada tarjeta debe incluir:
- Icono.
- Nombre.
- Descripción breve.
- Botón **Solicitar información** que abra WhatsApp.

### 4. ACERCA DE LA CONSULTORA
Título: **Sobre Consultora Admin**

Explicar brevemente que Consultora Admin ayuda a empresas a analizar problemas administrativos, diseñar soluciones, mejorar procesos y acompañar su implementación.

No inventar:
- Clientes.
- Años de experiencia.
- Certificaciones.
- Estadísticas.
- Testimonios.
- Títulos profesionales.

### 5. FOOTER
Incluir:
- **CONSULTORA ADMIN**
- Breve descripción.
- Enlaces internos.
- Botón/enlace de WhatsApp.
- Espacio preparado para futuras redes sociales.

## DISEÑO

La estética debe ser:

**Profesional + moderna + estratégica + tecnológica + empresarial.**

Utiliza:
- Tipografía moderna.
- Fondos claros.
- Azul oscuro/verde como base.
- Color de acento para CTA.
- Tarjetas con bordes redondeados.
- Sombras suaves.
- Buen espacio en blanco.
- Animaciones sutiles.
- Excelente experiencia móvil.
